# AI Productivity Hub

Build a modern, responsive web application called AI Workplace Productivity Assistant.

The app should include:

- Smart Email Generator

- Meeting Notes Summarizer

- AI Task Planner

Requirements:

- Clean, modern dashboard UI

- Sidebar navigation with 3 sections (Email, Notes, Planner)

- Each section must have:

  - Input box

  - Generate button

  - Output display area

- Allow users to edit AI responses

Design:

- Professional SaaS style

- Mobile and desktop responsive

- Simple and clean layout

Also include a disclaimer at the bottom:

"This AI may produce incorrect results. Always review outputs before use."
